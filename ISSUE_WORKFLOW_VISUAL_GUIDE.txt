│                                                                         │
│  Status Control:                                                        │

│  ✅ Can change: Open → In Progress → Resolved                          │
│  ❌ Cannot close issues                                                 │
│  ✅ Can add comments                                                    │

│  ❌ Cannot change priority                                              │
│  👁️  Views: Only assigned issues                                        │
│                                                                         │

│     ↑               ↑                    ↑                ↑            │

│                    (Can reopen and move to any status)                 │

EXAMPLE 1: Normal Issue Resolution
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│  1. 👤 Staff creates issue                                              │
│     Status: OPEN 🔴                                                     │
│     Department: VAT                                                     │
│                                                                         │
│  2. 👔 HOD assigns to staff member                                      │
│     Assigned To: John Doe                                               │
│                                                                         │
│  3. 👤 Staff starts working                                             │
│     Status: OPEN 🔴 → IN PROGRESS 🟡                                    │
│                                                                         │
│  4. 👤 Staff completes work                                             │
│     Status: IN PROGRESS 🟡 → RESOLVED 🟢                                │
│                                                                         │
│  5. 👔 HOD reviews and closes                                           │
│     Status: RESOLVED 🟢 → CLOSED ⚫                                      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

EXAMPLE 2: HOD Reopens Issue
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│  1. Issue is CLOSED ⚫                                                   │
│                                                                         │
│  2. 👔 HOD discovers problem                                            │
│                                                                         │
│  3. 👔 HOD reopens issue                                                │
│     Status: CLOSED ⚫ → IN PROGRESS 🟡                                   │
│                                                                         │
│  4. 👔 HOD reassigns to different staff                                 │
│     Assigned To: Jane Smith                                             │
│                                                                         │
│  5. 👤 Staff resolves again                                             │
│     Status: IN PROGRESS 🟡 → RESOLVED 🟢                                │
│                                                                         │
│  6. 👔 HOD closes                                                       │
│     Status: RESOLVED 🟢 → CLOSED ⚫                                      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
