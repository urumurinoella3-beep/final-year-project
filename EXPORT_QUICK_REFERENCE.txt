📊 DATA VALIDATION PAGE
───────────────────────────────────────────────────────────────

SUPPORTED FORMATS:
  ✓ CSV (.csv)        - Full validation
  ✓ Excel (.xlsx)     - Full validation  
  ✓ PDF (.pdf)        - Limited validation
  ✓ Word (.docx)      - Limited validation

FULL VALIDATION (CSV/Excel):
  • Data preview (first 5 rows)
  • Validation summary (total/valid/invalid)
  • Error detection (missing, duplicate, invalid format)
  • Create issue from errors
  • Download error report

LIMITED VALIDATION (PDF/Word):
  • Warning message displayed
  • Manual review recommended
  • Suggestion to convert to CSV/Excel

───────────────────────────────────────────────────────────────
📈 REPORTING & ANALYTICS PAGE
───────────────────────────────────────────────────────────────

EXPORT BUTTONS (Top of page):
  [PDF]  [Excel]  [CSV]  [Word]

EXPORT FORMATS:

1. PDF EXPORT:
   • Professional report with RRA logo
   • Executive summary with metrics
   • Charts and visualizations data
   • Issue details table
   • Multi-page with headers/footers

2. EXCEL EXPORT:
   • Two worksheets: Summary & Issues
   • Summary: All metrics and breakdowns
   • Issues: Complete issue data
   • Formatted headers

3. CSV EXPORT:
   • Simple CSV format
   • All issue details
   • Easy import to other systems

4. WORD EXPORT:
   • Professional document
   • Structured sections
   • Summary metrics
   • Issue details table

FILE NAMING:
  Admin:  DQIMS_System_Report_YYYY-MM-DD.[ext]
  HOD:    DQIMS_[DEPT]_Report_YYYY-MM-DD.[ext]
  User:   DQIMS_Personal_Report_YYYY-MM-DD.[ext]

───────────────────────────────────────────────────────────────
🔧 USAGE
───────────────────────────────────────────────────────────────

DATA VALIDATION:
  1. Click "Choose File" button
  2. Select CSV, Excel, PDF, or Word file
  3. View validation results
  4. Download error report or create issue

REPORTING:
  1. Select department (Admin only)
  2. Select date range
  3. Click desired export button (PDF/Excel/CSV/Word)
  4. File downloads automatically
