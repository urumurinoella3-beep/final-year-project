## Activity Log Features (Both Formats)

### What's Tracked
1. **Issue ID** - Unique identifier
2. **Title** - Issue title
3. **Current Action** - What's happening (Reported, In Progress, Resolved, Closed)
4. **Status** - Current status
5. **Priority** - Issue priority level
6. **Reported By** - Who reported the issue
7. **Assigned To** - Who is working on it
8. **Last Updated** - When last modified
9. **Days Open** - How long issue has been open

### Visual Indicators
- **Yellow Highlighting** - Issues open > 7 days (Excel & Word)
- **[URGENT] Tag** - In Word reports for urgent issues
- **Red Text** - Urgent entries in Word
- **Legend** - Explains color coding system

### Audit Trail Information
- Generation timestamp
- User who generated report
- User role and email
- Applied filters
- Confidentiality notice

## API Endpoints

### Generate Excel Report
```
GET /api/v1/reports/generate-excel
GET /api/v1/reports/generate-excel?department=Finance&status=OPEN
Authorization: Bearer {token}
```

**Response:** Excel file with 4 sheets, green headers, activity log

### Generate Word Report
```
GET /api/v1/reports/generate-word
GET /api/v1/reports/generate-word?department=Finance&status=OPEN
Authorization: Bearer {token}
```

**Response:** Word file with 6 sections, professional formatting, activity log

## Frontend Integration

### Reports & Analytics Page
```typescript
// Excel Download
const downloadExcel = async () => {
  const response = await fetch(
    'http://localhost:8080/api/v1/reports/generate-excel',
    {
      headers: { 'Authorization': `Bearer ${token}` }
    }
  );
  const blob = await response.blob();
  saveAs(blob, `DQIMS-Report-${date}.xlsx`);
};

// Word Download
const downloadWord = async () => {
  const response = await fetch(
    'http://localhost:8080/api/v1/reports/generate-word',
    {
      headers: { 'Authorization': `Bearer ${token}` }
    }
  );
  const blob = await response.blob();
  saveAs(blob, `DQIMS-Report-${date}.docx`);
};
```
