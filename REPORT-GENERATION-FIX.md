## How to Fix the 403 Error

The 403 error means the JWT token is either:
1. **Missing** - Not in localStorage
2. **Invalid** - Malformed or corrupted
3. **Expired** - Token has passed its expiration time

### Solution Steps:

#### Step 1: Login Again to Get Fresh Token
1. Open your frontend application
2. Logout if currently logged in
3. Login again with valid credentials:
   - Admin: `admin@rra.gov.rw` / `password`
   - HOD: `jean.mugisha@rra.gov.rw` / `password`
   - Staff: `grace.mukamana@rra.gov.rw` / `password`

#### Step 2: Verify Token in Browser Console
Open browser DevTools (F12) and run:
```javascript
console.log('Token:', localStorage.getItem('token'));
```

If token is null or undefined, you need to login again.

#### Step 3: Test Report Generation
After logging in with a fresh token:
1. Navigate to Reports & Analytics page
2. Click "Excel" or "Word" button
3. Report should download successfully
