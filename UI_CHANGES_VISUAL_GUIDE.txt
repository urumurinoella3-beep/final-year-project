FILE TYPE ICONS:

  ✅ CheckCircle2 (green)     → Valid/Success
  ❌ XCircle (red)            → Invalid/Error
  ⚠️  AlertTriangle (yellow)  → Warning

ERROR TYPE BADGES:
  🔴 ACCURACY       (red)     → Data accuracy errors
  🟠 COMPLETENESS   (orange)  → Missing data
  🟣 UNIQUENESS     (purple)  → Duplicate data
  🔵 FORMAT         (blue)    → Format errors

DATA VALIDATION:
  1. Click "Choose File"
     ↓
  2. Select file (CSV/Excel/PDF/Word)
     ↓
  3. View validation results
     ↓
  4. Download error report OR create issue

REPORTING:
  1. Select filters (department, date range)
     ↓
  2. Click export button (PDF/Excel/CSV/Word)
     ↓
  3. File downloads automatically
     ↓
  4. Open file in appropriate application
