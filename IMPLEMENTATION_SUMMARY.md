## 📝 IMPLEMENTATION NOTES

### Key Decisions:
1. **Limited validation for PDF/Word**: These formats are not structured data, so full validation is not possible. Users are warned and advised to use CSV/Excel.

2. **Separate export buttons**: Instead of a dropdown, we use separate buttons for each format for clarity and ease of use.

3. **Role-based reports**: Report content and file names adapt based on user role (Admin, HOD, User).

4. **Two-sheet Excel**: Summary sheet for metrics, Issues sheet for detailed data.

5. **RRA logo in PDF only**: Logo is embedded in PDF reports. Other formats use text branding.

### Technical Highlights:
- **xlsx library**: Handles both Excel and CSV generation
- **docx library**: Creates professional Word documents with tables
- **file-saver**: Ensures cross-browser file download compatibility
- **jsPDF**: Generates multi-page PDFs with custom styling
