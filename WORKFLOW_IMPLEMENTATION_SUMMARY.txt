✅ 1. NEW STATUS WORKFLOW
   Open → In Progress → Resolved → Closed

✅ 2. ROLE-BASED STATUS CONTROLS
   • STAFF: Open → In Progress → Resolved
   • HOD: Full control (including Close and Reopen)
   • ADMIN: View only (oversight role)

✅ 3. DEPARTMENT SELECTION
   • Added department dropdown when creating issues
   • Options: VAT, CUSTOMS, DOMESTIC TAX, IT
   • Easy to identify issue location

✅ 4. HOD ASSIGNMENT CAPABILITIES
   • HOD can assign issues to staff
   • HOD can reassign issues
   • HOD can change priority
   • HOD can close and reopen issues

✅ 5. ADMIN OVERSIGHT
   • Admin views all issues (no department)
   • Admin can assign and prioritize
   • Admin cannot change status (oversight only)


┌───────────────────────────────────────────────────────────────────────────┐
│  ROLE PERMISSIONS SUMMARY                                                 │
└───────────────────────────────────────────────────────────────────────────┘

👤 STAFF (Member):
   ✅ Create issues with department selection
   ✅ Change status: Open → In Progress → Resolved
   ✅ Add comments
   ❌ Cannot close issues
   ❌ Cannot assign issues
   👁️  Views: Only assigned issues

👔 HOD (Head of Department):
   ✅ Create issues with department selection
   ✅ Change status: Open → In Progress → Resolved → Closed
   ✅ REOPEN closed issues
   ✅ Assign issues to staff
   ✅ Change priority
   ✅ Add comments
   👁️  Views: All department issues

👨‍💼 ADMIN:
   ✅ Create issues with department selection
   ✅ Assign issues
   ✅ Change priority
   ✅ Add comments
   ❌ Cannot change status (view only)
   ❌ No department (system-wide view)
   👁️  Views: ALL issues across all departments
