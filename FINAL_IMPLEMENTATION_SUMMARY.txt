✅ 1. NOTIFICATIONS WHEN ASSIGNED TO ISSUES
   • Backend sends notification on assignment
   • Backend sends notification on reassignment
   • Notifications appear in bell icon
   • Click notification to view issue

✅ 2. HOD DEPARTMENT FILTERING
   • HOD sees ONLY their department issues
   • HOD can assign to department staff
   • Admin sees ALL issues (system-wide)

✅ 3. ISSUE DETAILS PAGE
   • New page: /issues/:id
   • Full issue information
   • All attachments visible & downloadable
   • Complete comment thread
   • Status/Priority/Assignment management
   • Timeline with dates

✅ 4. AUTO-STATUS CHANGE
   • Staff opens OPEN issue → Auto IN_PROGRESS
   • Saves time and clicks
   • Only for staff members

✅ 5. ACTION BUTTONS
   • "Mark as Resolved" (IN_PROGRESS → RESOLVED)
   • "Close Issue" (HOD only, RESOLVED → CLOSED)
   • "Reopen Issue" (HOD only, CLOSED → OPEN)

✅ 6. CLICK-TO-VIEW NAVIGATION
   • Click any issue in table → View details
   • Click any issue in kanban → View details
   • Easy navigation throughout app

┌───────────────────────────────────────────────────────────────────────────┐
│  NOTIFICATION SYSTEM                                                      │
└───────────────────────────────────────────────────────────────────────────┘

WHEN NOTIFICATIONS ARE SENT:
  1. Issue created with assignment
     → Notification to assigned user
  
  2. Issue reassigned
     → Notification to new assigned user

NOTIFICATION CONTENT:
  Type: ISSUE_ASSIGNED
  Title: "New Issue Assigned" or "Issue Assigned to You"
  Message: "You have been assigned to issue: [Title]"
  Link: Direct link to issue details

NOTIFICATION DISPLAY:
  • Bell icon in header
  • Shows unread count
  • Click to see all notifications
  • Click notification → Go to issue
  • Mark as read functionality
