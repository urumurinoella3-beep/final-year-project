## Current Issue: 403 Forbidden Error

### Why You're Getting 403
The JWT token in your browser is either:
1. **Expired** - Tokens have a limited lifetime
2. **Invalid** - Token was corrupted or modified
3. **Missing** - Not properly stored in localStorage

### Solution: Get a Fresh Token

#### Option 1: Use the Test Page (Easiest)
1. Open `test-report-generation.html` in your browser
2. Click "Login & Get Token" (credentials pre-filled)
3. Click "Generate Excel" or "Generate Word"
4. Report downloads automatically

#### Option 2: Login Through Your App
1. Open your React frontend
2. Logout if currently logged in
3. Login again with:
   - Email: `admin@rra.gov.rw`
   - Password: `password`
4. Go to Reports & Analytics page
5. Click Excel or Word button

#### Option 3: Test with curl
```bash
# First, get a token
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@rra.gov.rw","password":"password"}'

# Copy the token from response, then:
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:8080/api/v1/reports/generate-excel \
  --output report.xlsx
```
