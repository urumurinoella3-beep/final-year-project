## Current Report System

### Available Formats

#### 1. PDF Report (Frontend Generated)
- Quick summary report
- Generated client-side
- Good for quick viewing

#### 2. Excel Report (Backend Generated with Activity Log)
**Endpoint:** `GET /api/v1/reports/generate-excel`

**4 Professional Sheets:**
1. **Summary Sheet**
   - RRA branding
   - Report metadata (generated by, date, role, email)
   - Applied filters
   - Summary statistics
   - Issues by department

2. **Issues Sheet**
   - Complete data listing
   - All fields: ID, Title, Description, Status, Priority, Severity, Department, Reported By, Assigned To, Created Date, Updated Date
   - Professional table formatting

3. **Statistics Sheet**
   - Issues by Status
   - Issues by Priority
   - Issues by Severity
   - Professional tables with headers

4. **Activity Log Sheet** ⭐
   - Issue ID, Title, Current Action, Status, Priority
   - Reported By, Assigned To, Last Updated, Days Open
   - **Yellow highlighting** for issues open > 7 days
   - Legend explaining color coding
   - Complete audit trail

#### 3. Word Report (Backend Generated with Activity Log)
**Endpoint:** `GET /api/v1/reports/generate-word`

**6 Professional Sections:**
1. **Title Page**
   - RRA branding (blue header)
   - Report title
   - Report metadata (generated by, date, role, email)
   - Applied filters

2. **Executive Summary**
   - Overview paragraph
   - Key statistics (Total, Open, In Progress, Resolved, Closed, Completion Rate, Average Days Open)

3. **Detailed Statistics**
   - Issues by Status (table)
   - Issues by Priority (table)
   - Issues by Severity (table)
   - Issues by Department (table)

4. **Detailed Issues List**
   - Professional table
   - ID, Title, Status, Priority, Department, Assigned To, Created Date

5. **Activity Log & Audit Trail** ⭐
   - Professional table
   - ID, Title, Action, Status, Priority, Assigned To, Last Updated, Days Open
   - **Yellow background** for urgent issues (> 7 days)
   - **[URGENT] tag** in Days Open column
   - **Red text** for urgent entries

6. **Footer**
   - Generation timestamp
   - Confidentiality notice
   - RRA branding

## API Endpoints

### 1. Dashboard Statistics
```
GET /api/v1/reports/dashboard-stats
Authorization: Bearer {token}
```

### 2. Generate Excel Report
```
GET /api/v1/reports/generate-excel
GET /api/v1/reports/generate-excel?department=Finance
GET /api/v1/reports/generate-excel?status=OPEN
GET /api/v1/reports/generate-excel?startDate=2024-01-01T00:00:00&endDate=2024-12-31T23:59:59
Authorization: Bearer {token}
```

### 3. Generate Word Report
```
GET /api/v1/reports/generate-word
GET /api/v1/reports/generate-word?department=Finance
GET /api/v1/reports/generate-word?status=OPEN
GET /api/v1/reports/generate-word?startDate=2024-01-01T00:00:00&endDate=2024-12-31T23:59:59
Authorization: Bearer {token}
```
