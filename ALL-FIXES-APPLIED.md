### generateExcelReport() Method

```java
public byte[] generateExcelReport(String department, String status, 
                                  LocalDateTime startDate, LocalDateTime endDate) throws IOException {
    List<Issue> issues = getFilteredIssues(department, status, startDate, endDate);
    
    // Try to get current user, fallback to default if fails
    User currentUser = null;
    try {
        currentUser = currentUserService.getCurrentUser();
    } catch (Exception e) {
        currentUser = new User();
        currentUser.setName("System");
        currentUser.setEmail("system@rra.gov.rw");
        currentUser.setRole(UserRole.ADMIN);
    }
    
    // Create workbook...
    createSummarySheet(workbook, issues, currentUser, department, status, startDate, endDate);
    // ...
}
```

## Troubleshooting

### Still Getting 500 Error?
1. Check backend logs in terminal
2. Look for stack traces or error messages
3. Verify database is running (PostgreSQL)
4. Check if issues exist in database

### Still Getting 403 Error?
1. Verify you refreshed browser (Ctrl + Shift + R)
2. Check token: `localStorage.getItem('dqims_token')`
3. If token is null, logout and login again
4. Clear browser cache completely

### Reports Download But Are Empty?
1. Check if there are issues in the database
2. Verify filters aren't excluding all issues
3. Try without any filters first

### Backend Not Starting?
1. Check if port 8080 is already in use
2. Stop any other Java processes
3. Check PostgreSQL is running
4. Verify database connection in application.properties
