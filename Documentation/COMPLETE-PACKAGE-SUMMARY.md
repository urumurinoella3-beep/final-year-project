## 🎨 Diagram Export Guide

### For Best Quality in Thesis

**Recommended Format:** SVG (Scalable Vector Graphics)
- ✅ Scales to any size without quality loss
- ✅ Perfect for printing
- ✅ Small file size
- ✅ Supported by Word, LaTeX

**Alternative Format:** High-Resolution PNG
- ✅ Widely supported
- ✅ Good for presentations
- ⚠️ May lose quality when scaled

### Export Commands

```bash
# Export all as SVG (RECOMMENDED)
plantuml -tsvg Documentation/PlantUML/*.puml

# Export all as PNG
plantuml Documentation/PlantUML/*.puml

# Export specific diagram
plantuml -tsvg Documentation/PlantUML/19-System-Architecture-C4.puml
```

### VS Code Export
1. Install "PlantUML" extension
2. Open any `.puml` file
3. Press `Alt+D` to preview
4. Click export icon (top right)
5. Choose SVG or PNG
6. Save to your thesis folder

## 🎓 Academic Writing Tips

### 1. Don't Just Insert Diagrams
❌ Bad: [Insert diagram without explanation]
✅ Good: "Figure 4.1 shows the system architecture using the C4 model. The diagram illustrates three main containers: the Web Application (React frontend), the API Application (Spring Boot backend), and the Database (MySQL). As shown, users interact with the web application via HTTPS, which then communicates with the API using REST..."

### 2. Reference Diagrams in Text
✅ "As illustrated in Figure 4.1..."
✅ "The use case diagram (Figure 3.1) shows..."
✅ "Figure 4.5 demonstrates the deployment architecture..."

### 3. Explain Technical Choices
✅ "The system uses a three-tier architecture (Figure 4.1) because it provides separation of concerns, scalability, and maintainability..."

### 4. Use Consistent Numbering
✅ Figure 3.1, Figure 3.2, Figure 3.3...
✅ Table 4.1, Table 4.2, Table 4.3...

### 5. Add Meaningful Captions
✅ "Figure 4.1: DQIMS System Architecture using C4 Model showing the main system containers and their relationships"
