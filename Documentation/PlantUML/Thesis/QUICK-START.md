## 🚀 Generate Images NOW (3 Steps)

### Step 1: Go to PlantUML Online
Open: http://www.plantuml.com/plantuml/uml/

### Step 2: Copy & Paste
1. Open any `.puml` file (e.g., `Figure-04-Admin-Authentication-UserManagement.puml`)
2. Copy ALL the content
3. Paste into the PlantUML website
4. Click "Submit"

### Step 3: Download
- Click "PNG" to download image
- Save as: `Figure-04.png`
- Repeat for all 7 diagrams

---

## 📄 Insert into Word (2 Steps)

### Step 1: Insert Image
1. In Word: Insert → Pictures
2. Select the PNG file
3. Resize to 16cm width (keeps A4 format)

### Step 2: Add Caption
1. Right-click image → Insert Caption
2. Type: "Figure 4: System Administrator - Authentication & User Management"
3. Add description below (2-3 sentences)
